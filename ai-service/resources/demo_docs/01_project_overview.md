# TrustAgent 项目说明（演示文档）

> 本目录下的所有文件都是**合成的演示文档**，用于 `search_local_docs` 工具检索。
> 它们不包含任何真实企业内部信息。

## 项目定位

TrustAgent 是一个 AI Agent 安全网关与评测平台，包含三个进程：

1. **Java 控制面**：负责身份认证、RBAC、Agent 应用与安全策略管理、限流幂等、
   Trace / 安全事件 / 审计留痕、评测任务编排与指标复算。
2. **Python 执行面**：负责 LLM 调用、Agent 编排、输入/输出安全检查、
   工具调用前的策略校验、以及批量评测 Worker。
3. **Vue 管理端**：登录、应用与策略配置、Playground、评测与报告、Trace 详情、
   安全事件、审计链验证。

## 四个内置工具

| 工具 | 作用 | 是否有副作用 |
| --- | --- | --- |
| `calculator` | 四则运算（AST 白名单求值，不用 eval） | 否 |
| `search_local_docs` | 检索本目录的演示文档 | 否 |
| `query_traffic_metrics` | 查询合成交通指标 | 否 |
| `send_notification` | 写入本地 Mock Outbox | 是（默认不启用） |

## 设计主线

控制面掌握"谁能做什么、策略是什么、结果如何留痕"，执行面专注"把 LLM 与工具跑起来"。
安全判断放在**工具真正执行之前**，并且由策略数据决定，而不是靠 Prompt 提醒模型。
